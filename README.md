# VPnBot network policy

Публичные клиентские проекции единой сетевой политики VPnBot. Файлы здесь
генерируются из канонического `vpnbot_egress_policy.json`; вручную списки в этом
репозитории не редактируются.

Исходная политика SHA-256: `b6a9f99acd45ad4bad2e505156e9abd043cc6279d2421815ea83483e8bf6e9bf`.

## v2rayN для Windows

1. Откройте в главном меню v2rayN «Настройка региональных пресетов» → «Россия».
   Этот шаг задаёт российские источники `geoip.dat` и `geosite.dat` из
   [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat).
2. Обновите Geo-файлы через меню проверки обновлений.
3. В окне обычных настроек замените поле «Источник правил маршрутизации
   (необязательно)» на:

   `https://git.zapret.moe/zapretkvn/vpnbot-network-policy/raw/branch/main/v2rayN/template.json`

4. Откройте «Настройка правил», выберите
   `VPnBot: Всё, кроме российских сайтов`, выполните «Импорт правил из URL» и
   установите этот набор активным. Названия пунктов могут немного отличаться
   между версиями v2rayN, но исходный URL остаётся тем же.

После первого импорта повторяйте обновление правил из URL, когда v2rayN не
обновляет внешний шаблон автоматически. Сам публичный набор VPnBot и его
Mihomo-проекции обновляются без изменения адресов.

Правила проверяются сверху вниз. Поэтому разрешённые исключения VPnBot идут
через VPN раньше, чем общее правило отправляет российские домены и сети напрямую.

## Mihomo / Clash Meta

Профиль, выданный ботом, уже содержит ссылки на файлы из каталога `mihomo` и
обновляет их каждые 6 часов. Ручная настройка не нужна.

## Внешние данные

- `geoip:ru`, `geoip:ru-blocked`, `geosite:ru-blocked` и
  `geosite:ru-available-only-inside` предоставляет
  [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat).
- Дополнительные сети Яндекса, VK и Ozon строятся по проверенным ASN через
  RIPEstat. Yandex Cloud намеренно не включён: это многопользовательское облако.
